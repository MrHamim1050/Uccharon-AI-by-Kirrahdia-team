# Uchcharonai

A Bangla speech and phoneme-checking tool, built by team Kirrhadia to help users practice Bangla pronunciation. Users record their voice, get it transcribed, and see exactly which words didn't match the target sentence, highlighted in red.

**Live app:** https://uccharon-ai-by-kirrahdia.lovable.app

## Features
- Record your voice with a large microphone button, live waveform, and timer
- Automatic transcription via speech-to-text
- Compares your speech to a target sentence and highlights mismatched words

## Tech stack
React · TypeScript · Lovable · Speech-to-Text API
